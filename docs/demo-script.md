# 3-minute demo — shot list

One continuous golden path. Protect the last two days before submission for shooting this — hackathon videos recorded the last night lose.

| Time | Beat |
|---|---|
| 0:00 | The pain, in one breath, over three disconnected screens: saved posts, a notes-app plan, six fare tabs. |
| 0:15 | Onboarding: five vibes picked, a dozen swipes, the taste meter visibly moving. |
| 0:30 | **S1 live** — "Day trip in Singapore CBD, must eat chicken rice, then somewhere quiet" goes in; the route comes back on the map; two alternatives browsed with a swipe; one wildcard stop revealed. |
| 1:10 | **S3 live** — nobody searched. The November long-weekend alert lands: 3 destinations + one sealed wildcard. One card expands into a fully planned trip. |
| 1:40 | Booking: verify → masked summary → explicit approval of the exact total → Sandbox order number, PNR, and ticket number on screen. |
| 2:15 | **S4, the level-4 moment** — flight swapped, day one reflows, the budget bar moves by the fare delta, one narration line. |
| 2:30 | Evidence flash: the request panel with live call IDs and timestamps, plus one line on the Qoder build and model routing. |
| 2:40 | Close: "one graph, one budget, moves first." The B2B sentence for this room. Title card. |

## Rules for the shoot

- Sequence so the **unprompted alert (S3)** and the **flight-swap reflow (S4)** read as the headline — not the chat-planning scene, which is table stakes.
- Every major screen carries a visible Atlas-derived element; raw Atlas API responses appear on screen at least twice.
- Nothing is mocked without an on-screen label. Illustrative wireframe prices are never mistaken for the live fare board.
- Baseline/observed-fare badges only appear once ≥7 nights of real snapshot history exist — don't fake this for the shoot.
