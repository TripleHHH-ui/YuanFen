# Qoder platform notes (researched 2026-08-24)

*Web-researched summary for the evidence checklist — sources are official docs (docs.qoder.com)
unless marked; relayed from search/fetch, not hands-on use. Companion to `qoder-evidence-checklist.md`.*

## What matters for us

- **Qoder IDE** = standalone desktop editor (VS Code fork), current 1.25.1 (Aug 2026). Also CLI +
  JetBrains plugin. Free plan = limited credits + 2-week Pro trial (~300 credits); Pro $20/mo
  (2,000 credits), Pro+ $60 (6,000), Ultra $200 (20,000). Quest/Experts burn credits fast — the
  trial won't cover a hackathon build; check what the hackathon master account provides.
- **Quest Mode** is the unit of evidence: per-quest transcript, execution log, Spec tab, diff view,
  Summary panel (references Repo Wiki / Memory / Skills / MCP used), then Review-and-submit →
  commit/push/PR from inside Qoder. "My Quests" kanban board shows all of it.
- **Spec-driven flow**: toggle Spec on the Quest input → Qoder writes a 4-part Spec (Requirement /
  Design plan / Task breakdown / Acceptance criteria) → review/annotate → **Build**. Our
  `docs/PRD.md` + `docs/plans/2026-08-24-local-first-mvp.md` are structured to paste straight in
  (one quest per plan task).
- **Scheduled Tasks**: created in Quest via `/schedule`; fields: name, time, instructions, model,
  Goal toggle. **Runs locally — the IDE must be running at fire time** ("Keep system awake"
  setting exists). Cron/recurrence format and skill availability in scheduled runs: not documented
  (likely available since scheduled runs are Quest runs — inference). This is where the nightly
  fare-board job lives (`infra/scheduled-tasks/`).
- **Skills**: Anthropic-style; `npx skills add <repo> -a qoder` or project-local
  `.qoder/skills/<name>/SKILL.md`. The Atlas skill install command from the user guide works as-is.
- **Experts Mode**: built-in team (Lead Agent + Researcher, Full-Stack, QA, Code Reviewer, UI
  Operator, Debug Engineer); per-expert model override via Quest → Setting → Agents (Lead Agent
  model is NOT customizable). Custom sub-agents = markdown at `.qoder/agents/<name>.md`
  (frontmatter: name, description; optional model/tools/skills/mcpServers). Our
  FareBoardAgent/RouteAgent/TasteAgent map to three custom sub-agents with cheap/expensive
  model routing (RouteAgent gets the expensive tier).
- **Security scans**: L1 static (free, at generation), L2 semantic post-task, L3 deep pre-push
  taint analysis (L2/L3 cost credits). Run on: Atlas credential handling, passenger-detail
  zero-logging, chat-parser injection surface — keep the reports.
- **The 80% metric**: Teams portal → Data & Analytics → **"AI Share of Committed Code"** (share of
  committed lines generated by Qoder tools, per repo, main-branch filterable). Caveat that bites
  us: **code written with third-party tools (e.g. Claude Code) counts in the denominator but not
  the numerator** — local-first code merged as-is deflates the score. Mitigation: treat the
  local-first build as reference/spec, re-drive core code through Qoder quests, commit via Qoder's
  flow, screenshot the dashboard near submission.
